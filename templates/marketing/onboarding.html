CoreCloud onboarding

  1. Configure the environment: set a production secret key, database URL, allowed hosts and HTTPS deployment settings.
  2. Create the administrator: run python manage.py createsuperuser and sign in at /admin/.
  3. Set the organization: create departments, a payroll policy, roles and approval responsibilities.
  4. Import employees: add employees individually or use the CSV import, then verify authorization and initial password changes.
  5. Validate payroll: record test attendance and leave, generate a test payroll, review the breakdown, then approve a country-specific policy.
  6. Review privacy choices: face login is optional; collect consent before registration and provide password login as an alternative.

Do not use the demo account or sample data for production payroll. Replace all sample organization and contact details before launch.
